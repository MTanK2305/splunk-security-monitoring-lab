# Security Event Monitoring using Splunk

## Overview
This project demonstrates a SOC Analyst home lab built using Splunk Enterprise, Sysmon, and Windows Event Logs.

## Objectives
- Collect Windows Security and Sysmon logs
- Build SIEM dashboards
- Perform threat hunting
- Create SPL detection rules
- Map events to MITRE ATT&CK

## Technologies
- Splunk Enterprise
- Splunk Universal Forwarder
- Sysmon
- Windows Event Logs
- SPL
- MITRE ATT&CK
